# Security Playbooks Glossary

This glossary defines common terminology used throughout the repository for cybersecurity, detection engineering, security operations, and incident response.

## 1. Alert

A security notification generated by a detection rule, security control, or monitoring system indicating potentially suspicious or security-relevant activity that requires review or triage.

## 2. Indicator of Compromise (IOC)

An observable artifact or value that may indicate malicious activity or compromise. Examples include IP addresses, domains, URLs, file hashes, filenames, email addresses, and other identifiable artifacts associated with suspicious activity.

## 3. Detection Rule

A technical rule or logic used to identify potentially suspicious, malicious, or policy-violating activity within security telemetry.

Examples include **Sigma, YARA, and Suricata rules**.

## 4. Triage

The initial process of reviewing an alert or security event to determine its relevance, priority, severity, potential impact, and whether further investigation or response is required.

## 5. Investigation

A structured process of collecting, correlating, and analyzing security evidence to determine the nature, scope, timeline, and potential impact of suspicious or malicious activity.

## 6. Incident Response

The coordinated process of identifying, analyzing, containing, eradicating, and recovering from a confirmed or suspected security incident.

## 7. MITRE ATT&CK

A globally accessible knowledge base that documents adversary tactics, techniques, and sub-techniques based on real-world observations of attacker behavior.

## 8. Playbook

A structured and repeatable procedure that defines the actions, decision points, investigation steps, escalation criteria, and response activities for a specific security scenario.

## 9. Evidence

Information collected during an investigation that supports the analysis, validation, classification, correlation, and response to a security event or incident.

Examples include process execution data, logs, authentication events, file metadata, network activity, endpoint telemetry, and timestamps.

## 10. False Positive

An alert or detection triggered by legitimate, benign, or expected activity that does not represent malicious or unauthorized behavior.
