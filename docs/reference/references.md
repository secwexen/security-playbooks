# External References

The following resources are recommended for security research, detection engineering, threat intelligence, incident response, and adversary emulation.

## Detection Engineering & Rules

- [MITRE ATT&CK](https://attack.mitre.org/) — Adversary tactics, techniques, and procedures (TTPs) for detection engineering and threat hunting.
- [Sigma HQ](https://github.com/SigmaHQ/sigma) — Generic, platform-agnostic detection rules for SIEM systems.
- [YARA Documentation](https://yara.readthedocs.io/) — Pattern matching and malware identification using YARA rules.
- [Suricata Documentation](https://suricata.io/) — Network threat detection, intrusion detection, and network security monitoring.

## Security Standards & Frameworks

- [NIST Cybersecurity Framework](https://www.nist.gov/cyberframework) — Cybersecurity risk management and security program development.
- [NIST Incident Response Guide](https://nvlpubs.nist.gov/nistpubs/SpecialPublications/NIST.SP.800-61r2.pdf) — Incident response processes, preparation, detection, analysis, containment, and recovery.
- [OWASP](https://owasp.org/) — Application security guidance, testing methodologies, and common security risks.
- [MITRE D3FEND](https://d3fend.mitre.org/) — Knowledge base of defensive cybersecurity techniques mapped to adversary behaviors.

## Threat Intelligence & IOC

- [VirusTotal](https://www.virustotal.com/) — File, URL, domain, and IP reputation analysis and IOC enrichment.
- [MISP](https://www.misp-project.org/) — Threat intelligence sharing, IOC correlation, and threat data management.
- [Kaspersky Threat Intelligence Portal](https://www.kaspersky.com/enterprise-security/threat-intelligence-portal) — Threat intelligence research, threat investigation, and IOC analysis.
- [MalwareBazaar](https://bazaar.abuse.ch/) — Malware sample intelligence, sample identification, and malware-related IOC research.

## SIEM & Log Analysis

- [Elastic Security Labs](https://www.elastic.co/security-labs) — Threat research, detection engineering, and adversary tradecraft analysis.
- [Microsoft Security Blog](https://www.microsoft.com/security/blog/) — Security research, threat intelligence, and emerging attack techniques.
- [Splunk Documentation](https://docs.splunk.com/) — SIEM searches, event analysis, dashboards, and security monitoring.
- [Microsoft Security Documentation](https://learn.microsoft.com/security/) — Security product documentation, investigation workflows, and defensive configuration guidance.

## Detection Validation & Adversary Emulation

- [Atomic Red Team](https://github.com/redcanaryco/atomic-red-team) — Small, focused tests for validating security controls and detection rules.
- [MITRE Adversary Emulation Library](https://github.com/center-for-threat-informed-defense/adversary_emulation_library) — Adversary emulation plans based on real-world threat actor behaviors.
- [MITRE CALDERA](https://github.com/mitre/caldera) — Automated adversary emulation and security assessment platform.
