# Threat Intelligence

This directory contains structured threat intelligence resources used to collect, organize, and operationalize information about adversary behavior, campaigns, malware, indicators, and relevant intelligence sources.

Threat intelligence supports detection engineering, hunting, incident response, and risk-based security workflows by turning raw signals into actionable context. The content in this module is intended to help analysts correlate observed activity with known adversary behavior, malware families, and campaign characteristics.

## Purpose

The threat intelligence materials in this repository are designed to help defenders:

- Catalog threat actors and ransomware groups
- Track known campaigns and malicious activity
- Manage intake and dissemination of intelligence feeds
- Analyze and enrich indicators of compromise (IOCs)
- Map malware families to behaviors and operational context
- Maintain threat context for investigation and detection tuning

## Directory Structure

- `actors/` - threat actor profiles and reference templates
- `campaigns/` - campaign summaries, tracking notes, and templates
- `feeds/` - intelligence feed management and operational guidance
- `indicators/` - IOC enrichment and analysis templates
- `malware/` - malware family intelligence and reference docs
- `mappings/` - mapping and correlation assets for threat intel normalization
- `reports/` - intelligence reports and analysis summaries
- `sources/` - external and internal intelligence source references
- `vulnerabilities/` - vulnerability and exploit-related intelligence assets
- `tlp.md` - TLP classification guidance
- `README.md` - overview and navigation for this module
